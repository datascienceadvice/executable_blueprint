# Исполняемый проект: параметризованная генерация отчётов

**PowerShell-скрипт** для автоматической генерации отчётов о прецизионности хроматографических данных. Работает в двух режимах: **черновик** (маски-заполнители) и **финал** (реальные данные из Excel).

## Возможности

- Чтение данных из `.xlsx` (колонки `ID`, `area`)
- Расчёт статистик: среднее, СКО, ОСКО, минимум, максимум
- Автоматический вердикт: ОСКО ≤ 2 % → соответствует / не соответствует
- Построение гистограммы площадей пиков через Excel COM
- Генерация отчёта в `.docx` через Word COM
- **Режим черновика**: вывод масок `[x.xxx]`, графика-заглушки, шаблонного текста
- **Финальный режим**: подстановка реальных данных, значений и вердикта
- Авто-именование выходных файлов: `Report_draft.docx` / `Report_pass.docx` / `Report_fail.docx`

## Требования

- Windows
- Microsoft Excel (любая версия с COM-доступом)
- Microsoft Word (любая версия)
- Модуль PowerShell: `ImportExcel` (установка: `Install-Module -Name ImportExcel -Scope CurrentUser`)

## Быстрый старт

```powershell
# Установка модуля (однократно)
Install-Module -Name ImportExcel -Scope CurrentUser

# Черновик (маски)
.\mvp.ps1 -Mode draft

# Финальный отчёт — данные, проходящие критерий
.\mvp.ps1 -Mode final -sheetName pass

# Финальный отчёт — данные, не проходящие критерий
.\mvp.ps1 -Mode final -sheetName fail
```

## Подготовка данных

Файл `data.xlsx` с листами, именованными по сценарию:

| ID | area |
|----|------|
| S1 | 5234.5 |
| S2 | 5312.8 |
| S3 | 5287.1 |
| S4 | 5198.6 |
| S5 | 5265.3 |
| S6 | 5221.9 |

## Параметры

| Параметр     | По умолчанию       | Описание |
|--------------|--------------------|----------|
| `-Mode`      | `final`            | `draft` — черновик, `final` — финал |
| `-DataPath`  | `data.xlsx`        | Путь к файлу данных |
| `-sheetName` | `pass`             | Имя листа с данными (pass / fail) |
| `-ReportPath`| (авто)             | Путь для сохранения (по умолчанию `Report_<суффикс>.docx`) |

Если `-ReportPath` не указан, имя формируется автоматически:
- `Report_draft.docx` — в режиме черновика
- `Report_<sheetName>.docx` — в финальном режиме

## Сценарии

В `data.xlsx` два листа:

- **`pass`** — штатное соответствие (ОСКО 0,81 %, вердикт: соответствует)
- **`fail`** — несоответствие (ОСКО 4,23 %, вердикт: НЕ соответствует)

## Структура отчёта

1. **Заголовок** — режим (черновик / финал)
2. **Источник и дата генерации**
3. **Исходные данные** — таблица ID / Площадь (в черновике — маски `[x.xxx]`)
4. **Расчётные показатели** — n, среднее, СКО, ОСКО, минимум, максимум (в черновике — маски)
5. **График** — гистограмма (в черновике — заглушка)
6. **Вердикт** — соответствует / не соответствует (в черновике — бинарная маска)
